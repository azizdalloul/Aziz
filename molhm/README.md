# ملهم — نظام تجربة العميل والحجز (MOLHM)

Next.js 14 + TypeScript + Tailwind + Supabase (Auth / Postgres / Realtime). RTL عربي، Mobile-first.

## التشغيل المحلي
```bash
cp .env.example .env.local   # عبّئ قيم Supabase
npm install
npm run dev                  # http://localhost:3000
npm test && npm run lint     # 22 اختباراً + type-check
```
بدون Supabase تعمل الصفحات العامة ويقبل المعالج الإرسال بوضع تجريبي (رقم MLH-DEV-0000، لا يُخزَّن شيء). اللوحة تتطلب Supabase.

## إعداد Supabase
1. أنشئ مشروعاً، ثم نفّذ بالترتيب: `supabase/migrations/0001_schema.sql` ← `0002_rls.sql` ← `supabase/seed.sql`.
2. Auth → أنشئ مستخدمَين (عبدالعزيز، هبة) وعطّل التسجيل العام (Disable signups).
3. أضف ملفيهما: `insert into profiles (id, full_name, role) values ('<uuid>','عبدالعزيز دلول','admin'), ('<uuid>','هبة','operations');`
4. فعّل MFA (TOTP) من Auth → ثم اضبط `REQUIRE_MFA=true` عند جاهزية التسجيل.
5. Realtime مفعّل على جدول `leads` من الـmigration.

## الأدوار
- **admin (عبدالعزيز):** كل شيء، بما فيه الأسعار والمحتوى.
- **operations (هبة):** الطلبات، الحالات، الملاحظات، المواعيد، التصدير. لا تعدّل الأسعار/المحتوى (يُفرض في الـServer Action وفي RLS).

## الأمان (مُنفَّذ)
- لا INSERT عام: العميل يرسل عبر `/api/requests` (Zod + rate limit + honeypot + Turnstile اختياري + idempotency + منع تكرار نفس البريد خلال 10 دقائق). الخادم يستخدم service role، ولا يصل للمتصفح.
- RLS على كل الجداول؛ بيانات العملاء للموظفين فقط. الكتالوج المنشور فقط للعامة.
- `/admin/*` و`/api/admin/*` خلف Middleware + فحص الدور في الـlayout + RLS. Headers أمنية و`noindex`.
- منع الحجز المزدوج بفهرس فريد جزئي على `bookings(slot_id)`.
- لا بيانات عملاء في LocalStorage: المسودة (الخدمة + الدرجات فقط) في `sessionStorage` وتُمسح بعد الإرسال. نتيجة العميل تُعرض في جلسة متصفحه فقط وبموافقته.
- تصدير CSV بحماية من حقن الصيغ وBOM للعربية (يُفتح في Excel)، ويُسجَّل في `audit_logs`.

## الاستمارة الأصلية
- منقولة حرفياً من صور المالك: مهنتك، البلد («أين تقيم الآن»)، رقم الهاتف (التوضيح الدولي)، بريدك الإلكتروني، والبنود السبعة 1–10 بالترتيب، وحقل «هل تود بإضافة ملاحظات/طلبات أخرى». المعرَّف في `form_questions.origin = original_form`.
- **غير منقول بعد:** «قائمة الاختيار الإلزامية قبل مهنتك» وأقسام الأعلى — لم تظهر كاملة ولا تُخمَّن. أرسل صورة كاملة أو صلاحية Forms API لاستيرادها.
- الإضافات (الاسم، الفئة العمرية، الخدمة، الهدف، التواصل، الموعد، الموافقات) موسومة «إضافة» في الواجهة.
- لا قبول/رفض آلي من الدرجات؛ الدرجات في أعمدة رقمية منفصلة `score_*` وتاريخ كل تقييم محفوظ في `form_answer_sets`.

## Google Sheets (اتجاه واحد)
1. أنشئ Service Account وفعّل Sheets API، وشارك الملف مع بريده كمحرر (الملف مقيّد الصلاحيات).
2. عبّئ `GOOGLE_*` في البيئة. تُدفع الحقول التشغيلية فقط؛ الدرجات تُرسل فقط عند `SHEETS_INCLUDE_SCORES=true`.
3. التزامن عبر طابور `sheets_outbox` (upsert بحسب رقم الطلب → idempotent) وإعادة محاولة حتى 8 مرات؛ `vercel.json` يشغّل `/api/cron/sheets` كل 10 دقائق (يتطلب `CRON_SECRET`).

## النشر على Vercel
1. ادفع المستودع، واستورد المشروع في Vercel (Root Directory = `molhm`).
2. أضف متغيرات `.env.example` في Settings → Environment Variables (السرية بدون `NEXT_PUBLIC`).
3. Domains → أضف النطاق المخصص واضبط `NEXT_PUBLIC_SITE_URL`. في Supabase Auth → URL Configuration أضف النطاق.
4. لم يُنشر شيء بعد؛ يلزم حسابا Supabase وVercel وصلاحيات النطاق.

## النسخ الاحتياطي والخصوصية
- Supabase: فعّل Daily Backups (أو PITR) ونزّل نسخة دورية من `pg_dump`.
- الاحتفاظ المقترح: حذف الطلبات غير المتابعة بعد 12 شهراً (يُعتمد). حذف `leads` يحذف تقييماته وموافقاته (cascade). طلبات الوصول/التصحيح/الحذف تُنفَّذ يدوياً وتُسجَّل.
- نص الخصوصية والشروط وسياسة الإلغاء مسودات تحتاج اعتماداً قانونياً قبل الإطلاق.

## المحتوى والأسعار
- الأسعار المؤكدة فقط: مكتبي 60د = 1,150، 90د = 1,400 ر.ق. الباقات (4/6/8/10) وغيرها غير منشورة وتعرض «تواصل لمعرفة الأتعاب» حتى تُنشر من الإدارة → الإدارة.
- نصوص الصفحات في `site_content` وتُحرَّر من الإدارة (JSON) مع رجوع تلقائي للافتراضي في `src/lib/content.ts`.
- صورة الكوتش والشهادات: مواضع محجوزة، لا تُنشر قبل توثيقها وتزويدها من المالك.

## غير مفعّل عمداً
واتساب التلقائي (يتطلب WhatsApp Business API وموافقات)، وبريد الفريق (`TEAM_EMAIL_WEBHOOK_URL` جاهز كمتغير فقط)، وإنجليزية الواجهة (الـRTL والنصوص مهيأة لإضافتها).
